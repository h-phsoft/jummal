# دراسات عددية في القرآن الكريم

(دمج مشروعي جمّل و PhsQuran)

منصة الدراسة العددية للقرآن الكريم: حساب الجمّل والجداول المخصصة والأوفاق ودراسة الأرقام، مع تحليلات السور والآيات.

- **يعمل دون إنترنت**: موقع PWA يُثبَّت على الجهاز، وبرنامج exe لويندوز.
- **ملفات فقط**: لا قاعدة بيانات. البيانات في `data/` والحساب في المتصفح.
- **حساب واحد**: كل الحسابات في `packages/core`، يستدعيها المتصفح (وتُضاف واجهة برمجية لاحقاً لمن يريد).

## البنية

| المجلد | المحتوى |
|---|---|
| `data/` | بيانات القرآن (الآيات، الكلمات، السور): المصدر الوحيد |
| `packages/core/` | `@jummal/core`: كل الحسابات + اختباراتها |
| `frontend/` | الواجهة (React + Vite + PWA) |
| `desktop/` | برنامج سطح المكتب (Electron) |
| `tools/` | حزمة النشر على cPanel |

دليل التطوير الكامل لمن يكمل العمل: **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**

## الأوامر

```bash
npm install          # مرة واحدة
npm run dev          # تشغيل الواجهة للتطوير
npm test             # اختبار الحسابات والبيانات
npm run build        # بناء الموقع في frontend/dist
npm run desktop      # تشغيل برنامج سطح المكتب
npm run build:exe    # بناء ملف exe محمول في desktop/release (أو build-exe.bat)
npm run package:cpanel  # حزمة zip للرفع على cPanel في release/ (أو package-cpanel.bat)
```

## النشر

عند الدفع إلى `main` يبني GitHub Actions الموقع ويرفع `frontend/dist` إلى cPanel، ويبني ملف exe ويحفظه في صفحة التشغيل.

## قواعد البيانات النصية

- **الدراسة والحساب**: `ayat28Text` و `text28` (الحروف الـ 28).
- **البحث بدون تشكيل**: `ayatOText` / `ayatSearch` و `otext`.
- **البحث بالتشكيل**: `ayatNText` و `ntext`.
- **الحروف الـ 28**: الهمزة المنفردة (ء) تُحذف، أ إ آ ← ا، ة ← ه، ؤ ← و، ى ئ ← ي، وواو العطف كلمة مستقلة.
